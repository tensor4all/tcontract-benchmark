# result-v2/

Timing-v2 pages and indexes, owned by the shared toolkit:

- `result-v2/tcbench/INDEX.md` — the `tcbench` campaign index.
- `result-v2/per-shape/INDEX.md` — the `per-shape` (`lukbench`) campaign index.

Both are generated by `python3 -m campaign_toolkit.gen_index --write` with the matching
descriptor; do not edit them by hand. The legacy timing-v1 pages and `result/INDEX.md`
stay in `result/` and are never rewritten by the v2 pipeline.

Nothing has been recorded yet, so both indexes list their cells as `missing`. See
`docs/v2-layout.md`.
