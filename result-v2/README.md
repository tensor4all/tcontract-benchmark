# result-v2/

Timing-v2 pages and indexes, owned by the shared toolkit:

- `result-v2/tcbench/INDEX.md`, `HISTORY.md` — the `tcbench` campaign: the pages measured
  at the pin, and every other page.
- `result-v2/per-shape/INDEX.md`, `HISTORY.md` — the `per-shape` (`lukbench`) campaign.

All four are generated by `python3 scripts/v2/gen_index.py <campaign> --write`; do not
edit them by hand. The browsable site (each campaign's landing page and history, an HTML
copy of every page, the per-case charts and the trend charts declared in
`benchmarks/campaign-<campaign>.yaml`) is written by `scripts/v2/gen_site.py` on every
Pages deploy and never committed. The legacy timing-v1 pages and `result/INDEX.md` stay
in `result/` as frozen history. See `docs/v2-layout.md`.
